# Code of Conduct

Let's keep it simple: **Be nice.**

This project is meant to be a helpful tool for the community. Whether you're a senior dev or just writing your first Python script, you are welcome here.

- Treat everyone with respect.
- Be constructive when giving feedback.
- No harassment, trolling, or personal attacks.

If someone is being a jerk, let me know by opening an issue or reaching out directly, and I'll handle it. Let's just write good code and help each other out!
